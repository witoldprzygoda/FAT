# eta_sim — analysis of the SMASH simulation for pi+ pi- e+ e-

Everything of the simulation study of the two eta signals in M(pi+ pi- e+ e-) lives here.

| where | what |
|---|---|
| `plots/eta_sim/*.C`, `*.h` | macros and the weighted engine of this study (run from the repository directory, e.g. `root -l -b -q plots/eta_sim/<macro>.C`) |
| `plots/eta_sim/figs/` | figures (png, pdf); not in git, regenerated by the macros |
| `plots/eta_sim/tables/` | small text tables with the numbers quoted in the reports |
| `/hdd3/przygoda/HADES/FAT_out/sim/pippimepem_betanew/` | FAT outputs of the simulation (`output_{std,lep}_{pippimepem,pippimepep,pippimemem}.root`) and large intermediate files (`scan/`) |

Inputs: SMASH standard (`ppee_std_all.root`), lepton (`ppee_lep_all.root`) and eta (`ppee_eta_all.root`, added 2026-11-12,
section "Eta set") sets.
Rules for weights and classes: `src/sim_truth.h`. Simulation uses pure channel signals selected with the generator
codes (no combinatorial background); the data study is in `plots/scan_*.C` with figures in `plots/output/eta_scan/`.

## Eta set

The step that adds the SMASH eta set (sim_set = 3: every eta forced into pi+pi-e+e- or X17 pi+pi-) to the simulation and
compares the full simulation with data. User guidance (2026-11-12): SMASH describes the multi-pion background above the eta
structures badly, so the simulation is judged only in eta-enriched selections (mainly p p eta, some p p eta X) with
M4 < 1 GeV/c2; a mismatch is a result for discussion. Simulation = std (owned, mode A) + lep (owned, mode A) + eta (owned),
w (PDG), T1 + T2, no CB; variant (a) adds the ghost-flagged true pairs; sigma = sum w / 221.05 nb^-1 per set. Data (N - CB) /
L_data with L_data = 6080.5 nb^-1 UNCONFIRMED. X17 only as a shape for an illustrative BR = 1e-5, never summed.
E1 (slides) = pre + oa_lab < 50, eta_rest > 140, M(pipi) < 0.46, OA > 2; E2 = E1 without OA > 2.

Peak normalisation (`tables/eta_summary_peak_methods.txt`, figure f): the data peak is not larger than the simulated one; by
the data-study method (P_main on data and simulation) it is 0.36-0.84 of the simulation, methods that use the simulated
background shape give 0.66-1.36; it is known only to a factor of about 2. Withdrawn: "the simulated peak is 3.3 times larger"
(method A only, 0.29 +- 0.02 (stat) +- 0.06 (model) in pre) and "about 2 times". Peak classes (pre) with the fit-model spread
in the data errors: one common factor chi2/ndf 9.5/4 (OA) and 10.8/4 (M(ee)), formerly 39/4 and 34/4 with statistical errors
only; qualitatively the data have far more peak at OA > 10 deg and M(ee) > 20 MeV (0.28 +- 0.07 of the peak) than either
simulated component (0.046). The QED-reshaped direct decay is an illustration of shapes only (flat acceptance and fixed
content assumed): no fit result of it is quoted. Bump: the simulated bump is too large relative to the simulated background
at the bump edge; the fit factor lies between about 0.13 and 0.51 depending on model, range, scale and ghost variant (poor
fits, not a yield). Above 0.56 the spectrum is 81-90 % multi-pion background, which SMASH does not describe; its level there
is 0.87-1.36 times SMASH depending on selection, ghost treatment and vertex slice.

## Physics reweighting

Index of everything that belongs to the physics reweighting of the simulated eta decays (2026-11-12). Write-up in Polish
for the analysis group: `docs/SYMULACJA_ETA_GENERATOR.md` (the observation and its evidence in three steps, the converter
configuration, the consequences, the formulas, the results before / after, the limitations and the recommendations for
the producers). Method details: the two sections below. Observation in short: the eta set's eta -> pi+pi-e+e- (PLUTO
"eta:e+,e-,pi+,pi-", eta_physics plugin disabled) has a non-QED M(ee) already at generator level: 0.320 of the decays

## Physics reweighting of the eta decays (`sim_eta_physics.h`, `sim_rw_build.C`)

Added 2026-11-12. The eta set's eta -> pi+pi-e+e- was generated by PLUTO as a plain four-body channel ("eta:e+,e-,pi+,pi-"
via AddDecay, eta_physics plugin off): its M(ee) is not QED (27 % in 1.02-1.52 MeV, 4.7 % above 20 MeV at generator level).
User decision: correct with weights, no new production. `sim_eta_physics.h` holds every formula with its source;
`sim_rw_build.C` builds and validates the weights:

    root -l -b -q -e 'gSystem->SetBuildDir("/hdd3/przygoda/HADES/FAT_out/sim/pippimepem_betanew/scan/aclic_rw_build", kTRUE)' 'plots/eta_sim/sim_rw_build.C+(7)'

## Summary of the study (`sim_summary.C`)

`sim_summary.C` (function `sim_summary(int parts = 31)`; bits 1 (a), 2 (b)+(c), 4 (d), 8 (e), 16 (f)) recomputes the key numbers
from `sim_compact.root` and the data compact file and draws the six key figures in one style (data N black, CB red, N - CB blue,
simulated components as coloured lines or filled histograms; every figure states the selection, the normalisation,
L_data = 6080.5 nb^-1 (unconfirmed) and that eta -> pi+pi-e+e- is missing in the simulation). The template fit (f) reuses
`sim_templatefit.C` through `#include` (namespace `stf`, not modified); the data-derived cut efficiencies (e) are read from
`tables/cuts_compare_data.txt`. Numbers: `tables/summary_recomputed.txt`; one-page summary with sources: `tables/summary.txt`.
About 65 s, 9 GB:

    root -l -b -q -e 'gSystem->SetBuildDir("/hdd3/przygoda/HADES/FAT_out/sim/pippimepem_betanew/scan/aclic_summary", kTRUE)' 'plots/eta_sim/sim_summary.C+'

Other macros of the study (see their headers): `sim_datacomp.C` (data against simulation, R, OA classes, CB content),
`sim_templatefit.C` (PRELIMINARY template fit), `sim_closure.C` + `sim_closure_analysis.h` (lep/std closure, partition modes,
rules-v1 gaps, ghost leptons, code dictionary), `sim_tofmom.C` (tof_mom one vs two segments, beta_new and PID).

## Figure index (`figs/`)

Every file in `figs/`, grouped by study; `.png/.pdf` = both formats exist. Units nb/(GeV/c2) unless stated;
data use L_data = 6080.5 nb^-1 (unconfirmed); the direct decay eta -> pi+pi-e+e- is missing in every simulated curve
of the first study (files not starting with `eta_`); the `eta_*` files include it (section "Eta set").
