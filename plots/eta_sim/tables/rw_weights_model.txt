# T(q, M) = KW(q) x p*^3 lambda^{3/2}(m_eta^2, M^2, q^2) x |F_V(M^2)|^2 x |F_VMD(q^2)|^2 [x angular factors]
#  KW(q) = (2 alpha/(3 pi q)) (1 + 2 m_e^2/q^2) sqrt(1 - 4 m_e^2/q^2)                 Kroll-Wada, Phys. Rev. 98 (1955) 1355
#  p*^3 lambda^{3/2}: P-wave pi pi gamma* rate per dM(pipi) (|A|^2 ~ p*^2 lambda sin^2 th_pi, phase space ~ lambda^{1/2} p* dM^2 / M)
#      = (beta_pi^3 M^3 / 8) lambda^{3/2}; q -> 0: p*^3 (2 m_eta k)^3, the eta -> pi+pi-gamma rate (Stollenwerk et al., PLB 707 (2012) 184)
#  F_V: Guerrero-Pich, PLB 412 (1997) 382, hep-ph/9707347 (pi + K loops, f_pi = 92.4 MeV); variant Gounaris-Sakurai, PRL 21 (1968) 244
#       m_rho = 0.7753 GeV, Gamma_rho = 0.1491 GeV (as in the X17 slides)
#  F_VMD = m_V^2 / (m_V^2 - q^2 - i m_V Gamma(q^2)), m_V = m_rho; Gamma(q^2) = 0 below 4 m_pi^2 (whole q range)
#  angles (V3): e+ (1 + cos^2 + 4 m_e^2/q^2 sin^2) [transverse gamma*], pi+ sin^2 [P wave]: the phi-average of the full density
#      sin^2 th_pi (1 - beta^2 sin^2 th_e sin^2 phi) of the same amplitude; the phi term (V4) is checked in rw_weights_planes.txt (below 0.5 %)
#  V0 = KW x P-wave phase space; V1 = V0 x |F_V|^2; V2 = V1 x |F_VMD|^2; V3 = V2 x angular factors (MAIN since the review of 2026-11-12)
#  the M(ee) and M(pipi) marginals of V3 equal those of V2 (the angular factors are normalised at each q): rows 'V2' below hold for V3
# m_eta = 0.548 GeV (PLUTO value of the generator), m_e = 0.00051100, m_pi = 0.13957039 GeV, alpha = 1/137.036
